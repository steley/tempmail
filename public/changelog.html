What's New

The latest improvements, fixes and features on TempMail.cc — newest first. We ship continuously; here are the changes that actually matter to you.

October 15, 2026

  • NewInstall TempMail as an app. The site is now a lightweight PWA — add it to your home screen and open your inbox straight from there.
  • NewClearer error messages. When something goes wrong, you'll see a short, reportable error code instead of a generic failure.
  • PerfFaster worldwide access. Pages are now cached at the CDN edge, and the live inbox connects over WebSocket first for quicker delivery.
  • FixHonest connection status. The status indicator now reflects the real state of your live connection instead of guessing.
  • FixMobile address display. Long temporary addresses now auto-fit on small screens instead of overflowing.
  • For self-hostersSimplified Chinese documentation is now available (README.zh-CN.md), and the maximum accepted mail size is configurable — it now defaults to 1 MB to fit small-memory containers.

October 14, 2026

  • NewDark mode and QR code sharing. The interface now follows your system theme, and you can generate a QR code of your temporary address to scan it on another device.
  • NewSmoother first-time experience. A clearer empty-inbox guide and subtle animations when new mail arrives.
  • PerfFaster page load. Removed render-blocking scripts so your inbox is ready sooner, especially on mobile.
  • FixReliable reconnection. Fixed an issue where a temporary inbox could appear to lose messages after an interrupted connection recovered.
  • FixRaw source view. The raw email source panel now closes correctly when clicking anywhere on the close button.

October 13, 2026

  • NewLaunch of the FAQ page. Answers to the most common questions about temporary email, privacy and limits — see the FAQ.
  • SecurityHardened the service. Added strict security headers, per-mailbox rate limiting and a full security audit pass.
  • FixClearer timestamps. Emails that didn't arrive today now show the month and day instead of a bare time.
  • FixMobile layout polish. Fixed several mobile display issues and cleaned up the footer.
  • For self-hostersDocker deployment guide. Complete documentation for running your own instance: clone, build, run, nginx WebSocket proxy and troubleshooting. See the About page for contact and project info.

Complete rewrite — October 2026

  • TempMail.cc is a complete rewrite of the 2015-era forsaken-mail project: a modern, dependency-clean stack powering a free temporary email service with a real-time inbox — no registration, no password, no personal data. Messages arrive the moment they are sent and are permanently deleted when your session ends. The full source is available on GitHub.
